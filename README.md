# THE [G]OLD MEMORIES

Link to Play: https://gabori.itch.io/the-gold-memories

An atmospheric 2D platformer about memories, darkness, and escape.

## Controls

| Key | Action |
|---|---|
| ← / → | Move |
| SPACE | Jump |
| SPACE (Hold) | Jump higher |
| E | Interact / Read Memory |

### 🌲 Climbing

You can climb on trees and branches using them similarly to **wall jumps**.

## About the Game

**THE [G]OLD MEMORIES** is an atmospheric 2D platformer built directly for the browser.

You play as a **Dreamer** trapped in a cold, suffocating purgatory. As darkness encroaches, your only hope of survival and escape lies in finding fragments of your lost, warm memories scattered across the void.

Explore the darkness.

Find what was lost.

Remember what it means to be warm.


Explore the void and collect fragments of your lost memories before the darkness consumes you.

**How much of yourself can you remember?**
